# CivicTrace
Civic Trace is a blockchain-powered civic complaint platform that makes issue reporting transparent, traceable, and accountable. 
Citizens can report public problems such as potholes, broken streetlights, water leaks, overflowing bins, and unsafe roads. They can then track their complaint, view authority updates, and verify or challenge a submitted resolution.
By recording key events in the complaint lifecycle on a tamper-resistant blockchain, Civic Trace creates a verifiable history of what was reported, what action was taken, and how the complaint was resolved.
Core Flow
Report → Track → Act → Resolve → Verify
Civic Trace uses Solidity smart contracts and the Ethereum Sepolia testnet as its trust layer, with MetaMask enabling users to interact with blockchain transactions.
The goal is simple: make sure every complaint can be traced, every action can be seen, and every resolution can be verified.
